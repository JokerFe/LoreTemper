# 分析控制页

本次范围：在映知本地工作台新增学习控制页，按任务选择 Ollama / Codex 订阅，动态发现模型与思考档位，选择单个/多个视频或递归目录，指定一个输出根目录，预览时长与消耗后加入队列。

- Codex 使用桌面客户端附带的 CLI、同一登录账户，通过 app-server 的 model/list 获取可见模型，不能将静态价格表冒充模型列表。执行固定推理，不使用 API 密钥，不自动切回本地。
- Codex 沿用主题取证流程，每次最多20分钟；长片分段取证，再综合成整课主题总结。自动处理完成标记待来源审阅，不生成最终 Skill。
- Ollama 保持原本本地流水线，动态列出已安装模型并验证视觉能力。每次任务冻结配置，切换不影响已有任务。
- 输入支持手写路径与本机文件选择器，不上传视频。显式选择仅导入选中视频，不自动监控整个父目录。输出保留来源、完整字幕、截图、总结与计量，按视频和运行ID隔离，不覆盖其他学习资料。
- 费用倍率以 GPT-6.1 Sol medium 标准速度为1×，以相同 token 结构和已核实 API 价格估算，不声称等于订阅额度扣费。未知模型显示暂无法估算。思考档位对token消耗影响未实测，不编造倍率。
- 验收：动态列表/不可用错误、任务配置冻结、重复输入去重、文件和目录选择、输出安全、取消/恢复、实际用量、原有流水线回归、桌面和窄屏交互。

## 2026-10-19：两个独立功能与串联流程

新增“视频学习”“笔记生成 Skill”“学习并生成 Skill”三种运行方式。两阶段分别配置引擎、模型、思考档位；自动配置先显示实际输入清单、模型和输出位置，提交时冻结这份具体配置。视频来源自动使用已配置的视频目录；独立Skill自动选取目录中实际存在且已审阅的主笔记；串联仅自动接收本次笔记，可手动补充其他资料，不能悄悄加入全部历史课程。

统一输出根目录下的 `notes/` 保存学习资料，`skills/` 保存每个流程独立的Skill包。Skill包包含SKILL.md、来源规则、原笔记索引及可取得的引用图片；不安装到全局技能目录。显式选择生成/串联即表示对该任务选定范围进入综合阶段，不表示所有未来课程都已提供完。生成后的状态为`generated_awaiting_validation`，结构验证与实际效果验证分开，不能据自动学习完成声称来源已人工审阅或正式Skill已发布。

Skill生成只处理笔记，不重新解码视频。长笔记先逐份/分块提炼，再合并规则，最后编写精简Skill入口；原笔记不截断、不覆盖。输入摘要和来源指纹保留，重试复用相同调用结果；资料变化要求新任务。自动模型在预览阶段优先Codex订阅，未登录或不可用时可选本地兼容模型；开始后不自动切换。Skill费用仅按字符数给宽范围粗估，串联的第二步在笔记实际生成后再计算，实际调用回执独立保存。

流程后台进程与原视频队列独立，串联等待全部视频任务生成成功后才衔接Skill；失败不进入下一步，暂停/取消保留中间资料。视频阶段失败后可在资料库定位具体原因，流程重试恢复原任务。仅打开页面或预览不会提交分析。恢复后不会重新学习成功的视频。

验证：新增9项后端流程测试与1项浏览器流程测试，全套68项后端、6项浏览器测试通过。覆盖独立运行、文本模型能力、自动选择、归档排除、暂停恢复、完整依赖与笔记交接、来源指纹、Skill结构检查、HTTP鉴权下的创建和预览、手动多行输入和配置变更后的预览失效。新Skill生成用明确模拟的推理结果验证，未擅自将当前全部课程生成或安装成Skill。
